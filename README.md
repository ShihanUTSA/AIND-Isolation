# AI Nanodegree Projects

Consolidated coursework from Udacity's Artificial Intelligence Nanodegree, combining four previously separate repositories into one place.

| Project | Description |
|---|---|
| [`isolation/`](isolation) | Build a Game-playing Agent — adversarial search agent for the game of Isolation, using minimax with alpha-beta pruning and custom heuristics. |
| [`planning/`](planning) | Implement a Planning Search — classical planning for an air cargo logistics problem using planning graphs and heuristic search. |
| [`recognizer/`](recognizer) | Sign Language Recognition System — probabilistic models (HMMs) for recognizing American Sign Language sequences. |
| [`sudoku/`](sudoku) | Diagonal Sudoku Solver — constraint propagation and search, including the naked twins technique. |

Each subfolder is self-contained with its own README, dependencies, and instructions — see the linked README in each for details on running that project.

This repository was formerly [`aind-isolation`](https://github.com/ShihanUTSA/AIND-Isolation); the other three projects were merged in from their own repositories (now archived): `AIND-Planning`, `AIND-Recognizer`, and `AIND-Sudoku`.
